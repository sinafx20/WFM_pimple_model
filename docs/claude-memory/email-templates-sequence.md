The **Volcano cold-email sequence** lives in `~/pimple-model-project/pimple-model/email-templates/`
(WFM_pimple_model repo; see [[pimple-model-project]]). Built for **Instantly** (cold outbound,
domain rotation), not HubSpot.

**Structure:** 7 touchpoints × 6 industries = 42 HTML files in per-industry subfolders
(`architecture/ engineering/ consulting/ creative/ construction/ civil/`), generated by a
script so structure stays identical and only tailored copy changes. Email map: 1 intro (`tool=intro`,
the ONLY email with a video) → 2 health-check (tp1) → 3 profit-leak (tp2) → 4 benchmark (tp3) →
5 demo (tp4) → 6 firms-like-yours (tp5; construction/civil use cross-industry stories, no video) →
7 resource-hub (tp6). Links go to the live `https://lp.workflowmax.com/app?tool=...` (Webflow
site is published; 404 is fixed). `master-branded.html` / `variation-2b-minimal-face.html` are the
design; `_gallery.html` previews all 42.

**Copy logic (also reused for the HeyGen video scripts, see [[heygen-personalization-studio]]):**
cost-of-inaction first, value-first ("even if WFM is never the right fit, you keep your number"),
single CTA, **no em dashes**. **Services** firms (architecture/engineering/consulting/creative) =
unbilled time / utilisation / over-servicing. **Project** firms (construction/civil) = quoted-vs-
delivered margin + the "variation black hole" (matches the tools' actual leak definitions).
Currency-agnostic ("five figures"), AU spelling.

**Tokens (Instantly):** `{{firstName}}` `{{companyName}}` `{{email}}` built-in; `{{industry}}`
custom CSV column. Subjects use spintax `{a|b}`. Signature = **Sina Zarei, Account Executive**;
footer address **1/525 Collins Street, Melbourne, VIC, 3000**. Logo = `WFM-Logo.png` (rasterized
from the repo's dark SVG via sharp; relative path for preview — host + swap to absolute before sending).
Still to fill before send: booking link, unsubscribe (Instantly auto-append), face thumbnail (email 1).
Only email 1 carries an image (the face video thumbnail); 2–7 are plain text + logo + one button.
